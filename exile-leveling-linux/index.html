Exile Leveling for Linux

The act tracker from Exile-UI, ported to Linux. It reads PoE's Client.txt, flips the leveling guide when you change zones and draws a small overlay – no AutoHotkey, no OCR, no touching the game.

Install Source

Ported 1:1 from Exile-UI

Same logic, same guide format, same settings files – just Python and Tkinter instead of AutoHotkey.

Auto guide

The bundled Act 1–10 guide jumps to the next page as soon as you enter the target zone, with the original 2-second grace period after manual paging.

PoB import

Copy a PoB code or pobb.in link and import it: the guide shows the quest rewards and gems to buy for your class and build.

Skill-tree overlay

Shows the current tree step from your PoB: newly allocated nodes in green, masteries numbered.

Zone layout hints

Turquoise terms in the guide are clickable and open the layout image – “opposite corners” and friends.

Act timer

Splits per act, automatic pause in the hideout and CSV export of your campaign runs.

XP & fade

Exact XP penalty calculator including the safe zone, and an overlay that fades out until you hover it or reach town.

Install

Python 3, Tk and Pillow – nothing else.

# Arch / CachyOS
sudo pacman -S tk python-pillow
# Debian / Ubuntu
sudo apt install python3-tk python3-pil
# Fedora
sudo dnf install python3-tkinter python3-pillow

git clone https://github.com/gamunex/exile-leveling-linux.git
cd exile-leveling-linux
./start.sh
  • Finds Client.txt in the default Steam paths, or pass --client /path/to/Client.txt.
  • PoE 1 only, running through Steam / Proton.
  • Always on top works reliably with the game in windowed or borderless mode. Tested on X11 / KWin.
  • Custom guides in Exile-UI's JSON format can be imported from the clipboard.

Based on Lailloken/Exile-UI (MIT). Guide data and graphics come from the original project – all credit for the tracker's design goes there.
